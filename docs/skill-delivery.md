## 生成链路

1. 客户选择商品类目与成片套路，上传一张清晰商品图。
2. 专用商品图反解析 PE 输出包装视觉锚点和可读文字原文。
3. 类目 Agent 第一层融合图片解析、商品事实与可选客户脚本。
4. 第二层按对应套路编译9:16、30秒 Seedance 2.5 完整成片 Prompt。
5. 痛点机制套路固定为一条主痛点对应一条有事实支持的表层机制；证据不足时降级为质地、真实使用动作和有限结果。
