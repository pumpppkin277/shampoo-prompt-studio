# 洗面奶场景口播使用演示成片生成

## 输入

要求商品图、商品名称、适用人群、一个标准主痛点、至少一个确认卖点和商品质地；客户脚本可选。主痛点仅接受：出油/污垢、洗后干燥紧绷、敏感刺激、痘痘黑头/毛孔污垢。

## 工作流

1. 读取 [references/script-understanding.md](references/script-understanding.md)，保留客户核心表达并过滤未确认事实。
2. 读取 [references/compiler.md](references/compiler.md)，解析商品包装与质地，推导生活场景、产品创意和正确洁面顺序。
3. 保持泡沫增长、上脸和冲洗连续，结果保留真实皮肤纹理。
4. 只输出一个无占位符的中文自然段。

## 输出要求

输出必须含9:16、30秒、完整时间轴、商品三次锚定、融合后的口播、质地/泡沫创意、取用起泡上脸冲洗、有限结果、音效和一致性约束，可直接复制到 Seedance 2.5。
