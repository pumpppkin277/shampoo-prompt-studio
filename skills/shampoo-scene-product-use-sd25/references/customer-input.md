# 客户输入契约

## 必需输入

```text
商品图：至少一张正面清晰图；建议增加侧面、背面、泵头和质地图
商品名称：
适用人群：
标准主痛点：头屑头痒 / 头皮出油、异味或扁塌 / 毛躁打结或易断
已确认核心卖点：至少一条
商品质地：客户确认；未提供时仅使用图片中可见事实
```

无需填写使用方法、可选场景、口播语气、活动信息或禁止项；Skill会根据类目、人群和痛点自动推导。

## 输入判断

- “青少年、儿童、宝妈、全家”是人群，不是主痛点。
- “运动后、夏季、晨起、洗头前”是场景，不是主痛点。
- “温和、成分安心、经过检测”是信任信息，不是主痛点。
- “透明啫喱、乳白液体、绵密泡沫、清新香味”是质地或使用体验，不自动等于功效。
- 客户没有确认的去屑、控油、舒缓、强韧、柔顺或保湿能力不得写入成片。

## 缺失信息处理

以下任一项缺失时先询问，不直接生成：商品图、标准主痛点、确认卖点。一次最多询问三个关键问题。使用方法、场景、口播语气和合规限制由Skill自动补全，不向客户追问。
