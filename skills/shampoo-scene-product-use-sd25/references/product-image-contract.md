# LabelGPT商品图解析契约

## 调用对象

- LabelGPT Agent：`7669651444601012234`
- 使用现有“智能帮写-参考生视频”PE的静态图片解析路由。
- 只传商品图片，不传视频；在用户指令中明确“只做静态商品图反解析”。

## 调用指令

将以下文字与商品图片一起输入现有PE：

```text
只对输入的商品图片进行静态反解析，不生成视频，不补写动作、运镜、音轨、时序或使用场景。请用一个中文自然段高保真描述图片中可见的商品事实，重点包括：商品数量和品类、瓶型或罐型、尺寸比例、主色与辅色、透明或磨砂等材质、瓶盖或泵头结构、标签版式、Logo和清晰可读文字、图案和色块位置、液体或膏体的可见颜色与透明度、商品朝向、拍摄角度、光线和反光。看不清的文字明确写不可辨识，不得编造；不得根据包装宣称推断实际功效。
```

## 归一化字段

收到一段式解析后，在内部整理为：

```text
商品品类：
商品数量：
包装形态与比例：
包装主色/辅色：
包装材质与反光：
瓶盖/泵头/瓶口结构：
Logo、商品名及真实文字：
标签色块与图案版式：
可见内容物颜色与透明度：
商品朝向和当前机位：
不可辨识信息：
```

## 商品视觉锚点写法

把可见事实压缩成80—180字的商品视觉锚点，至少包含包装形态、颜色、材质、泵头/瓶盖、标签层级、Logo或文字状态和内容物质地。例如：

```text
一瓶高约为瓶身宽度三倍的圆角透明PET泵瓶，瓶内为浅绿色透明啫喱，顶部是哑光白色鸭嘴泵头，正面标签由上方品牌Logo、中部商品名和下方两行小字组成，标签底部有浅绿色弧形色块；清晰文字按原样保留，不可读小字保持为模糊印刷区域。
```

## 事实边界

- 图片事实只能用于包装、质地、颜色、文字、数量、比例和材质。
- 包装上的卖点文字可作为“包装真实文字”保留，但不能自动成为产品能力。
- 客户文字与图片外观冲突时，先提示冲突；没有确认前不得擅自选择新包装。
- 多图存在差异时，以客户指定的主图为主，其余图片只补充泵头、背标和侧面结构。
