# Seedance 2.5完整成片Prompt编译器

## 编译目标

将商品视觉锚点和客户事实锚点写入一段可直接生成30秒成片的中文Prompt。最终不得留下 `{{变量}}`、括号说明、待确认项或抽象指令，例如“展示产品”“加入场景”“体现卖点”。所有内容都要实例化为具体画面和动作。

## 第一步：建立事实锚点

内部建立但不输出表格：

- 商品视觉锚点：来自LabelGPT商品图解析。
- 商品事实锚点：来自客户确认的适用人群、卖点、成分、质地、用法和活动。
- 禁止推断项：客户未确认的功效、使用频次、检测结论、治疗能力。

视觉锚点必须在4—8秒产品创意镜头、8—20秒使用介入镜头、26—30秒商品收尾镜头中重复出现，措辞可以压缩，但瓶型、颜色、材质、泵头、标签层级和文字状态必须一致。

一张主体清晰的正面商品图已经足够生成，不得因为缺背标、多角度或精确尺寸拒绝。先逐字抄录正面清晰可见的包装文字；商品镜头中引号内的瓶身文字只能来自这份抄录。客户填写的商品名称只可用于口播识别，除非图片上确有完全相同文字，否则不能写成包装文字；英文不得翻译或改成中文。

## 第二步：选择需求场景

根据主痛点选择一个可观察且易生成的场景：

- 头皮出油/异味/扁塌：青少年运动后回到浴室、晨起发现发根贴伏、摘下帽子后发根扁塌。
- 头屑头痒：洗头前拨开发缝发现少量白屑、穿深色上衣时发现肩部少量白屑、日常轻挠头皮。
- 毛躁打结/易断：家长晨起帮助孩子梳发、洗后吹干前发尾毛躁、梳齿经过发尾出现轻度卡顿。

场景只呈现一个主痛点，不同时堆叠头油、头屑、脱发和毛躁。人物年龄、服装、发型、场景和光线应能在后续镜头稳定复现。

## 第三步：生成口播

写一段70—110字的自然中文口播，拆入人物画内口播和延续性画外音。结构为：

`具体场景与痛点 → 一个使用前顾虑 → 已确认卖点 → 正确使用方法 → 有限度使用感受 → 合规行动提示`

台词必须使用中文双引号。不得照抄来源素材的品牌、夸张话术、促销数字或绝对化承诺。

## 第四步：选择产品创意

只选择一种主创意，保证可生成性：

- 透明啫喱或液体：泵头受力下压，内容物连续落入掌心；用侧逆光表现透明度、气泡和流动黏度。
- 乳白液体或膏体：瓶口挤出形成连续丝带或圆润堆叠纹理；镜头轻推近表现光泽。
- 泡沫型产品：泵头按压后泡沫在掌心逐渐形成，展示细密气泡和回弹；不得无来源突然爆发大量泡沫。
- 包装辨识度高但质地信息少：商品从浴室镜面倒影或水面倒影中移动揭示，随后转正展示标签。

创意动作必须符合包装结构。泵瓶才能按压，软管才能受挤压形变，翻盖瓶必须先开盖再倒出。

## 第五步：编排30秒镜头

默认六个镜头：

1. 0—4秒，需求场景中近景：人物、环境、发型和可观察痛点；人物开始口播。
2. 4—8秒，产品创意近景/微距：完整商品视觉锚点、质地物理、轻微运镜；口播转为画外音。
3. 8—12秒，取液与起泡近景：包装再次锁定，手与泵头/瓶口受力正确，质地进入掌心并起泡。
4. 12—19秒，真实使用中近景和局部近景：指腹按摩头皮或揉洗发丝，湿发、泡沫和手部接触连续。
5. 19—25秒，结果镜头：冲洗和吹干后，在相同人物与近似光线下展示与主痛点对应的有限结果。
6. 25—30秒，人物＋商品收尾：商品正面稳定、人物状态自然、口播结束，最后画面保持一秒以上。

可以在不破坏上述模块的前提下拆成七至八个镜头，但总时长必须闭合到30秒。

## 第六步：写成可执行Prompt

最终一个自然段必须依次包含：

1. 整体风格、画幅、时长和光线基调。
2. 人物锚点：年龄段、脸型、发型、服装和稳定特征；不得写真实名人。
3. 场景锚点：地点、主要陈设、光源方向和低干扰背景。
4. 以“视频0到4秒……”形式写完整时间轴，所有镜头自然衔接。
5. 商品视觉锚点在三个关键阶段重复锁定。
6. 口播原话、说话人、画内音/画外音状态和嘴型同步。
7. 环境声、背景音乐和关键动作音效。
8. 结尾状态和一致性约束。

## 一致性与物理规则

- 人物的脸、发型、发色、服装和年龄在全片保持一致；湿发到干发必须经过冲洗和吹干镜头。
- 包装文字、Logo、标签色块、瓶型、泵头和内容物颜色随机身运动稳定附着，不漂移、不镜像、不变形。
- 手指数量、抓握点、按压力、泵头回弹、液体流动、泡沫增长和冲洗消退符合物理逻辑。
- 不生成后期字幕、花字、贴纸、弹幕、平台界面和水印；只保留商品包装上真实存在的文字。
- 不用换光、换角度、换发型或过度修图伪造效果。

## 最终检查

内部确认：所有客户输入均已融合；没有占位符；商品8秒内识别；包装锚点出现至少三次；口播完整；使用动作顺序正确；结果与主痛点对应；没有虚构成分或功效；没有治疗、根治、永久、绝对安全、伪检测或生发表达。

检查通过后，只输出最终一个中文自然段，不输出任何解释。
