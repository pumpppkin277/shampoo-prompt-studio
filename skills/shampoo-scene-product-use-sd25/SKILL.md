# 洗发水场景口播成片生成

## 工作目标

接收客户商品图和商品事实，先解析商品视觉事实，再完成内容决策，最终只输出一段无占位符、可直接投喂seedance2.5的视频生成提示词。不得把分析过程、输入复述、分镜表或自检结果混入最终提示词。

## 执行流程

1. 按 [references/customer-input.md](references/customer-input.md) 检查输入。商品图、一个标准主痛点和至少一个确认卖点为必需项。
2. 将商品图传入 LabelGPT 现有图片反解析PE。使用 Agent `7669651444601012234` 的静态图片解析路由，并严格采用 [references/product-image-contract.md](references/product-image-contract.md) 中的调用指令和归一化字段。
3. 以图片解析结果建立“商品视觉锚点”；以客户文字建立“商品事实锚点”。客户只需提供商品名称、适用人群、标准主痛点、核心卖点和商品质地。使用方法按洗发水标准流程生成，场景与口播由人群和痛点自动推导。
4. 处理冲突：可见外观以商品图为准；功效、成分和用法以客户确认文字为准；无法确认的信息留空并询问，不得猜测。
5. 按 [references/seedance25-prompt-compiler.md](references/seedance25-prompt-compiler.md) 完成场景、人物、口播、产品创意、使用动作、结果和收尾的实例化。
6. 生成后按编译器中的检查清单内部校验。信息充分时只输出最终中文成片提示词；信息不足时只询问最多三个会改变成片结果的关键问题。

## 输出纪律

- 最终输出为一个中文自然段，不使用标题、列表、Markdown、解释或占位符。
- 最终提示词应包含明确的30秒时序、五至八个镜头、完整人物与场景、商品视觉锚点、真实物理动作、口播与声音、结尾状态和一致性限制。
- 推荐长度为900—1600个中文字符；以可执行和稳定为优先，不为凑长度堆砌形容词。
- 商品最迟8秒完成识别，包装锚点至少在产品吸睛、使用介入和结尾三个位置重复约束。
- 不生成后期字幕、花字、贴纸、平台界面和水印；包装上真实存在且清晰可读的文字可保留。
