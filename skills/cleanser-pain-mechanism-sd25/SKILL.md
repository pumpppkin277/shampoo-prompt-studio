# 洗面奶痛点机制成片生成

## 输入

要求商品图、商品名称、适用人群、一个标准主痛点、至少一个确认卖点和商品质地；客户脚本可选。主痛点仅接受：出油/污垢、洗后干燥紧绷、敏感刺激、痘痘黑头/毛孔污垢。

## 工作流

1. 读取 [references/script-understanding.md](references/script-understanding.md)，把脚本映射为痛点、产品、单一机制和有限结果。
2. 读取 [references/compiler.md](references/compiler.md)，解析商品图并锁定一条有卖点证据的表层机制。
3. 证据不足时取消内部机制，降级为掌心泡沫、正确洁面和有限结果。
4. 只输出一个无占位符的中文自然段。

## 输出要求

输出必须含9:16、30秒、完整时间轴、商品三次锚定、客户声音文本、唯一表层机制示意、真实结果、音效和一致性约束，可直接复制到 Seedance 2.5。
