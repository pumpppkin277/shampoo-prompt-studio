# 面霜场景口播使用演示成片生成

## 输入

要求商品图、商品名称、适用人群、一个标准主痛点、至少一个确认卖点和商品质地；客户脚本可选。主痛点仅接受：干燥缺水、干燥起皮/轻度皲裂、泛红敏感、痘痘/问题肌护理顾虑。

## 工作流

1. 读取 [references/script-understanding.md](references/script-understanding.md)，保留客户核心表达并过滤未确认事实。
2. 读取 [references/compiler.md](references/compiler.md)，解析商品包装与膏体，推导生活场景、单一产品创意和真实涂抹动作。
3. 结果与主痛点一一对应，保留真实皮肤纹理，不用换光或磨皮制造效果。
4. 只输出一个无占位符的中文自然段。

## 输出要求

输出必须含9:16、30秒、完整时间轴、商品三次锚定、融合后的口播、膏体创意、取膏点涂推开、有限结果、音效和一致性约束，可直接复制到 Seedance 2.5。
