# 洗发水痛点机制成片生成

## 输入

要求商品图、商品名称、适用人群、一个标准主痛点、至少一个确认卖点和商品质地；客户脚本可选。主痛点仅接受：头皮出油/异味/扁塌、头屑头痒/头皮敏感、毛躁打结/易断。

## 工作流

1. 读取 [references/script-understanding.md](references/script-understanding.md)，融合客户脚本并建立事实边界。
2. 读取 [references/compiler.md](references/compiler.md)，解析商品图并选择唯一受事实支持的痛点—机制链路。
3. 证据不足时取消内部机制，降级为质地微距、真实揉洗冲洗和有限结果。
4. 只输出一个无占位符的中文自然段，不附分析、自检或 Markdown。

## 输出要求

输出必须含9:16、30秒、完整时间轴、商品三次锚定、融合后的声音文本、真实使用动作、唯一机制示意、有限结果、音效和一致性约束，可直接复制到 Seedance 2.5。
